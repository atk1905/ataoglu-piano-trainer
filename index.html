Bridge notu

iPad Safari Web MIDI desteği sınırlı olabilir. Bluetooth MIDI için Web MIDI destekleyen bir tarayıcı/bridge gerekebilir. Uygulama secure context altında çalışır; izin verilirse doğrudan MIDI, verilmezse diagnostic görünüm aktif olur.

Verdiğin WebMIDIBrowser sayfasından port tarama, canlı hex log, statechange ve C3 output test özellikleri trainer içine taşındı.
